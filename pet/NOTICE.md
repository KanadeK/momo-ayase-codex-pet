# Notices and provenance

## Character

Momo Ayase is an existing character from DANDADAN. Character names, designs,
and related rights belong to their respective owners.

The project used the official DANDADAN character page as identity reference
during private generation review:

- https://anime-dandadan.com/en/character/

The official source image is not included in the repository, release archives,
or Git history. Shipped sprite assets are newly generated fan-art
reinterpretations and are covered by `ASSET_LICENSE.md`, not the MIT software
license.

## Software

PetEase and the repository's software are original work released under MIT.
Third-party Python packages retain their own licenses. Release packages include
checksums and a dependency inventory.

## Takedown contact

If you are a rights holder and want the fan-art assets removed, open a GitHub
issue titled `Rights holder request`. The maintainer will remove disputed
assets promptly while preserving unrelated MIT-licensed tooling where
appropriate.
